# ツムツム ゲーム範囲トレーナー

スクリーンショットを取り込み、ゲーム画面の範囲を四角で教えて学習する PySide6 アプリです。

## 起動

```bash
cd tsumtsum-screen-recognition
pip install -r requirements.txt
python main.py
```

## 使い方

1. 画像をドロップ、`Ctrl+V` で貼り付け、または「画像を開く」
2. ドラッグしてゲーム範囲を囲む（自動保存）
3. ラベルが数枚たまったら「学習する」
4. 新しい画像を入れると、学習済みモデルが範囲を予測します。違っていたら囲み直してください

学習データ（画像・ラベル・モデル）は `data/` に保存され、Git には含まれません。
