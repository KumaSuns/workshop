# メニューの取り込み

使うのは、このフォルダだけです。

## フォルダを取る

https://github.com/KumaSuns/auto_play をダウンロードします。

ZIP で取るときは、解凍した中のこのフォルダを使います。

`git clone` で取るときは、次を実行します。できた `auto_play` フォルダが、このフォルダです。

```
git clone https://github.com/KumaSuns/auto_play.git
```

## 起動する

Python 3.10 以降と、PySide6 が必要です。

```
pip install PySide6
python main.py
```

ウィンドウの名前は「AUTO PLAY」です。もう一度起動したときは、新しい窓は出ません。開いているメニューを前に出します。

## デスクトップのアイコン

メニューの「起動アイコンをデスクトップに作成」を押すと、デスクトップに `AUTO PLAY.lnk` ができます。次からは、そのアイコンで起動します。

## モデル

モデルのファイルは `models\scene.pt` です。

起動したとき、そのファイルとサーバーにある `scene.pt` を比べます。違うときは、左上の MODEL情報 のボタンが「更新する」になります。押すと、`models\scene.pt` に入ります。同じとき、またはサーバーと照合できないときは「更新なし」です。「更新なし」を押しても、取り込みはしません。

## 停止

プレイ中の停止は Q です。
